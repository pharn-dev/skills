## Mapping

- AC-1 | unit | `src/phargus/test/signals.test.mjs` | CLI `node src/phargus/runtime/phargus.mjs summarize --file <fifo>` (spawned with process.execPath, path built from import.meta.url; skipped on win32), where <fifo> is made with `mkfifo` in a mkdtemp directory and the test opens its write end with `O_WRONLY | O_NONBLOCK`, retrying on `ENXIO` until it succeeds (the readiness signal: the child has opened the FIFO for reading), and keeps that end open: on `child.kill('SIGTERM')` the child's `exit` event reports signal `SIGTERM` within 5 s and its stdout is empty; a second child on a fresh FIFO with `child.kill('SIGINT')` reports signal `SIGINT` within 5 s with empty stdout; and module src/phargus/runtime/commands.mjs export `main(args: string[]): Promise<unknown>` (imported inside the test body) awaited in-process (rejections caught) for `['help']`, `['summarize', '--file', <file of 3 sample() lines>]`, `['compare', '--before', <that file>, '--after', <that file>]`, `['capture', '--file', <that file>, '--out', <empty dir>]`, `['doctor', '--project', <dir with package.json "{}">]`, `['heap', '--project', <that dir>, '--file', <that file>]`, `['rules', '--project', <that dir>, '--file', <that file>, '--rules', <that file>]` and `['collect', '--project', <that dir>, '--file', <that file>]` leaves `process.listenerCount('SIGINT')` and `process.listenerCount('SIGTERM')` equal, after each call, to their values before the first; on a deadline the test kills the child with SIGKILL and closes the FIFO end, so it fails instead of hanging
- AC-2 | unit | `src/phargus/test/signals.test.mjs` | CLI `node src/phargus/runtime/phargus.mjs capture --file <fifo> --out <dir>` (spawned with process.execPath; skipped on win32), FIFO write end opened as in AC-1, then one line `JSON.stringify(sample(Date.now()))` written to it and kept open; once `<dir>/events.ndjson` holds a complete line (polled, with a 5 s deadline), `child.kill('SIGTERM')`; once the child's stdout holds its JSON result (5 s deadline) the test closes the FIFO end and awaits exit: `<dir>/manifest.json` parses with `termination` === "interrupted" and `quality.truncated` === true, and `node src/phargus/runtime/phargus.mjs summarize --file <dir>/events.ndjson --manifest <dir>/manifest.json` exits 0; the same with `capture --url <url> --out <dir2>` against a node:http server on 127.0.0.1 port 0 in the test process that answers 200 `content-type: text/event-stream`, writes `event: window\ndata: <JSON.stringify(window(Date.now()))>\n\n` and keeps the connection open (spawned asynchronously so the server can answer): after SIGTERM `<dir2>/manifest.json` has `termination` "interrupted" and `quality.truncated` true and the same summarize exits 0; and a third child `capture --file <fifo2> --out <dir3>` with the FIFO write end opened but nothing written, then SIGTERM: once the child's stderr holds its JSON error line (5 s deadline) the test closes the FIFO end and awaits exit, and `<dir3>` holds neither `events.ndjson` nor `manifest.json`; all three in one test, with the AC-1 deadline cleanup
